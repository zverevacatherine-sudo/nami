# Имёныш — сказочный frontend v6

Рабочая адаптивная демоверсия с иллюстрациями единорогов, интерактивным тестом и сохранением избранного в локальном браузере.

## Запуск
Откройте `index.html` в браузере. Для Vercel загрузите все содержимое папки (index.html вместе с assets).

## Важно
Это фронтенд-прототип. Оплата не подключена, база имён демонстрационная, полноценного личного кабинета нет.
Иллюстрации подготовлены из согласованного визуального референса для этой версии.
