# Имёныш — первая версия

Готовый адаптивный сайт на HTML, CSS и JavaScript, без необходимости устанавливать зависимости.

## Как открыть

Откройте `index.html` в браузере на компьютере. Для полноценной проверки на телефоне опубликуйте папку на хостинге (например, Vercel) и откройте публичный адрес с телефона.

## Что работает

- Адаптивная главная страница Dreamy
- 7 вопросов с интерактивными карточками и прогрессом
- Детерминированный подбор топ-5 по ответам из стартовой коллекции
- Избранное в localStorage текущего браузера
- Поделиться результатами через системное меню/буфер обмена
- Начать тест заново

## Чего пока нет

- Сейчас в `names.js` **100 имён**, а не 5000. Не следует рекламировать готовую базу 5000. Для выхода в продакшн нужны проверенные и лицензированные источники данных и расширение базы до 5000 реальных записей.
- Оплата **не подключена**, кнопка Plus заблокирована. Никто не может заплатить через этот прототип.
- Нет регистрации, хранения данных на сервере, кабинета, генерации PDF, фамилии и отчества.
- Частотность имён сейчас представляет условную классификацию, а не статистику России. Достоверную популярность нужно привязать к региону и году.

## Как опубликовать на Vercel

1. Создайте репозиторий на GitHub и загрузите в корень пять файлов: `index.html`, `styles.css`, `names.js`, `app.js`, `vercel.json`.
2. На Vercel выберите Add New → Project → Import Git Repository.
3. Framework Preset: Other. Build Command оставить пустой. Output Directory: `.`.
4. Deploy. После публикации сайт откроется и с телефона.
