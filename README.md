# Имёныш — Dreamy Demo v2

Обновлённая, более милая и сказочная версия сайта.

## Что улучшено
- Более dreamy-дизайн: мягкие градиенты, луна, звёзды, стеклянные карточки.
- Более красивые кнопки: градиенты, объём, сияние, округлые формы.
- Больше милых и тёплых фраз по всему сайту и в тесте.
- Улучшена мобильная адаптация.
- Вся демоверсия собрана в одном `index.html` для удобного запуска.
- Тест с подбором имён и сохранением избранного в браузере.

## Как открыть
1. Откройте файл `index.html` в браузере.
2. Либо загрузите папку на Vercel / Netlify / GitHub Pages.
