# Имёныш v5 — Облачные друзья

Новая версия дизайна: трогательный первый экран, более заметный бренд, разнообразные единороги и звёздочки на длинной странице. Сохранены интерактивный тест, избранное и показ Plus после получения результатов.

## Просмотр
Откройте `index.html` в браузере. Для публикации можно загрузить папку на хостинг статических сайтов (например, Vercel).

Важно: это демонстрация. Реальная оплата не подключена; база не содержит 5000 проверенных имён.
