# Имёныш v11 — unicorn stickers on site

Эта версия использует набор пастельных единорогов-стикеров на прозрачном фоне. Они встроены в существующий сайт как плавающие фигуры и заменяют старые SVG-единорогов в ключевых блоках.

## Что изменено
- В hero добавлены 3 парящих единорога.
- В блоках пожеланий, истории и в секции с единорогами старые SVG заменены на новые фигуры.
- Сохранены прозрачный фон, мягкое парение и адаптивность.

Откройте `index.html` вместе с папкой `assets`.
