# Имёныш — v5 «Книга наклеек»

Новый визуальный стиль «sticker book»: плотные контуры, пастельные цвета, милые персонажи-наклейки (единороги, мишка, луна, звёздочка, облачко) и бегущая лента. Прежняя версия — pastel dreamy: крупнее бренд, нежная история ожидания малыша, три летающих единорога в разных настроениях, звёздочки и облачка. Цены и тарифы **убраны с главной**. Небольшой блок будущих возможностей показывается только после прохождения теста; оплатить ничего нельзя.

## Как посмотреть

Откройте `index.html` в браузере. Для открытия с телефона опубликуйте эту папку на статическом хостинге и откройте ссылку с мобильного устройства.

## Статус

Это дизайнерский прототип со стартовой базой (не 5000 имён), тестом и избранным в памяти браузера. Нет сервера, реальных платежей или личных кабинетов.
